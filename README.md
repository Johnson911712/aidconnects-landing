# AidConnects Landing Page

Nigeria's #1 Peer-to-Peer Services Marketplace - Production-Grade Landing Page

## Features

- ✅ Hero Section with CTA buttons
- ✅ Social Proof & Stats Bar
- ✅ Compliance Badges Area
- ✅ How It Works Section
- ✅ Key Features Grid
- ✅ Service Categories
- ✅ Testimonials Carousel
- ✅ For Providers CTA
- ✅ App Download Section
- ✅ Trust Pillars Section
- ✅ Regulatory & Compliance Section
- ✅ Data Protection & Privacy Section
- ✅ Financial & Consumer Protection Section
- ✅ FAQ Section with Accordion
- ✅ Upgraded Footer with Compliance Links
- ✅ Dedicated Policy Pages

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Vite** - Build tool
- **React Router** - Navigation

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```
