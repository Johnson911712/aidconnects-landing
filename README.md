# AidConnects Landing Page

Nigeria's #1 Peer-to-Peer Services Marketplace - Production-Grade Landing Page

## 🚀 Overview

AidConnects is a comprehensive landing page for a peer-to-peer services marketplace with full regulatory compliance, consumer protection features, and trust-building components.

## ✨ Features

- ✅ **Hero Section** - Animated background with CTA buttons
- ✅ **Social Proof Bar** - Stats and metrics display
- ✅ **Compliance Badges** - 6 regulatory compliance badges
- ✅ **How It Works** - Dual flow for customers and providers
- ✅ **Key Features** - 8 feature cards with icons
- ✅ **Service Categories** - 8 category cards
- ✅ **Testimonials** - Customer and provider reviews
- ✅ **For Providers** - CTA section with earnings highlights
- ✅ **App Download** - iOS and Android download links
- ✅ **Why Trust AidConnects** - 8 trust pillars
- ✅ **Regulatory & Compliance** - Credential cards with verification links
- ✅ **Data Protection & Privacy** - NDPC compliance section
- ✅ **Financial & Consumer Protection** - FCCPC compliance section
- ✅ **FAQ Section** - Accordion-style FAQ with 6 questions
- ✅ **Upgraded Footer** - Multi-column layout with compliance links
- ✅ **9 Policy Pages** - Full legal documentation

## 🛠️ Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Vite** - Lightning-fast build tool
- **React Router** - Client-side routing
- **Biome** - Code linting and formatting

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or higher
- pnpm (recommended) or npm

### Installation

```bash
# Install dependencies
pnpm install
# or
npm install
```

### Development

```bash
# Start development server
pnpm dev
# or
npm run dev
```

The app will open at `http://localhost:3000`

### Build

```bash
# Build for production
pnpm build
# or
npm run build
```

### Preview

```bash
# Preview production build
pnpm preview
# or
npm run preview
```

## 📝 Configuration

### Update Brand Information

Edit `src/utils/constants.ts` to customize:
- Brand name and tagline
- Website URL and logo
- Contact information
- Regulatory credentials
- Company information

### Placeholder Content

All policy pages and regulatory information contain placeholders marked with `[...]`. Replace these with actual content:
- `[Contact Phone]` - Your phone number
- `[CAC Registration Number]` - Your CAC registration
- `[Legal Company Name]` - Your company's legal name
- etc.
